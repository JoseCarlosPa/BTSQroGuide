# Bienvenido a BTS Querétaro Guide

¡Hola! Te damos la bienvenida al espacio centralizado de documentación y buenas prácticas para la **Oficina de Querétaro**.

---

## 🎯 Propósito de este Portal

Este portal tiene como objetivo principal ser el punto de encuentro y consulta centralizado para todo el equipo de Querétaro:

- **Centralización**: Disponer de un único lugar accesible y actualizado para consultar cómo trabajamos.
- **Alineación CMMI**: Servirá como base para documentar y estandarizar gradualmente nuestros procesos bajo el modelo de madurez CMMI.
- **Cultura y Operaciones**: Facilitar la integración del equipo y la consulta de temas operativos del día a día.

---

## 🚧 En Construcción

Actualmente nos encontramos preparando la estructura y definiendo los activos iniciales. Próximamente se integrarán las secciones correspondientes a:

1. **Gestión de Proyectos**: Planificación, estimación y seguimiento.
2. **Ingeniería de Software**: Criterios de requerimientos, diseño, estándares de desarrollo y control de calidad.
3. **Soporte y Calidad**: Control de configuración y auditorías.
4. **Guía de Oficina**: Onboarding, herramientas e instalaciones locales.
