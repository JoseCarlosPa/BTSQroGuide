# Directorio de Herramientas y Sistemas

Relación de las plataformas y herramientas que utilizamos comúnmente en la oficina de Querétaro.

---

## 🛠️ Stack de Gestión y Comunicación

| Herramienta | Uso Principal | Solicitud de Acceso |
|---|---|---|
| **Slack / MS Teams** | Mensajería instantánea y canales de proyecto | IT Helpdesk |
| **Jira Software** | Gestión de tareas, sprints y seguimiento de incidencias | Project Manager |
| **Confluence / Docusaurus** | Base de conocimiento y procesos | Admin de Oficina |
| **Google Workspace / M365** | Correo corporativo, calendario y almacenamiento | IT Helpdesk |

---

## 💻 Stack de Desarrollo y Entrega

| Herramienta | Uso Principal |
|---|---|
| **GitHub / GitLab** | Repositorios de código fuente, PRs y pipelines de CI/CD |
| **SonarQube / Code Climate** | Análisis estático de calidad y seguridad de código |
| **AWS / Azure / GCP** | Ambientes de desarrollo, Staging y Producción |
| **VPN Corporativa** | Acceso seguro a redes internas y bases de datos |
